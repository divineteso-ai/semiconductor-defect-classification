# SEM Defect Classification with VAE-Based Data Augmentation

This repository contains archived Jupyter notebooks for a master thesis project on SEM defect classification. It compares a CNN baseline trained on original images with three training configurations that add synthetic Class 1 images generated by a variational autoencoder (VAE).

The project uses Classes 1, 3, and 4 of the Carinthia SEM dataset. Class 1 is the minority class. The notebooks document the original experimental workflow, including model training, evaluation, conformal prediction, and a final comparison of the configurations.

## Repository contents

| File | Description |
|---|---|
| `01_vae_class1_archived.ipynb` | VAE training and image generation for Class 1 |
| `02_cnn_baseline_archived.ipynb` | CNN baseline using original images only |
| `03_cnn_synthetic_10pct_archived.ipynb` | CNN training with 6 synthetic Class 1 images |
| `04_cnn_synthetic_30pct_archived.ipynb` | CNN training with 17 synthetic Class 1 images |
| `05_cnn_synthetic_50pct_archived.ipynb` | CNN training with 28 synthetic Class 1 images and a final comparison |

The augmentation percentages refer to the 55 original Class 1 images in the dataset:

- +10% corresponds to 6 synthetic images.
- +30% corresponds to 17 synthetic images.
- +50% corresponds to 28 synthetic images.

## Models and workflow

The CNN experiments use a frozen ImageNet-pretrained ResNet50V2 backbone with a trainable classification head. The classification head consists of global average pooling, dropout, and a three-class softmax output. The backbone is not fine-tuned.

The original images are split into training, calibration, and test subsets using a 70/15/15 stratified split. Synthetic images are appended only to the training subset. The VAE experiments generate Class 1 images; the CNN experiments then use selected synthetic images as additional training data.

The notebooks also implement a simple conformal prediction workflow. It computes nonconformity scores as one minus the predicted probability of the true class and uses a calibration threshold to construct prediction sets.

## Important interpretation notes

These notebooks are archived research artifacts. They preserve the original executable code and the outputs produced during the original experiments. They were not rerun for publication, and the stored results should not be treated as evidence of a fresh successful run.

Several methodological limitations are documented in the notebooks:

- The source VAE was trained on all 55 original Class 1 images, including images later assigned to calibration and test subsets.
- The calibration subset was used both for model selection and for conformal calibration.
- The test subset was reused for validation-based checkpoint selection in the baseline notebook.
- The archived conformal threshold uses NumPy’s default interpolated percentile rather than the finite-sample correction described in the thesis.
- The final comparison uses manually copied historical metrics from separate experiment outputs; it is not a fresh joint evaluation.
- The results do not include repeated training runs or uncertainty estimates.

Therefore, the results should be interpreted as exploratory historical findings rather than an independently validated benchmark or a verification of nominal conformal coverage.

## Data and execution

The notebooks refer to Google Drive paths from the original Colab workspace. They require the Carinthia SEM dataset and previously generated synthetic images. The repository does not include the dataset or generated images.

The notebooks can be opened in Google Colab or Jupyter. However, execution is not required to inspect the saved results and figures.

Running the notebooks may overwrite saved model checkpoints and figures in the original Google Drive workspace. Before any deliberate rerun, preserve the original model files, figures, and outputs.

Random seeds are set in the notebooks to support repeatability. They do not guarantee identical results across different hardware, software versions, or execution environments.

The notebooks are provided for transparency and archival purposes. They document the original workflow and results, but they do not constitute a fully independent replication package.
